# Amethyst Nails & Beauty — 2027

Static HTML, CSS and JavaScript website for Amethyst Nails & Beauty in Gainsborough.

## Included

- Main site with the cheque-shaped gift voucher design in purple on light card
- Recruitment and treatment-room hire pages
- Amethyst Glow game, reached via the footer gem
- Local photographs, icons and styles

Open `index.html` through any static web server. No framework, dependencies or build step are required. For GitHub Pages, use the `main` branch and the repository root.
